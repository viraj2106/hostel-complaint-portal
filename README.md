# Hostel Complaint Portal

A web-based Hostel Complaint Portal for registering, viewing and managing hostel complaints.

## Features

- Register hostel complaints
- View all registered complaints
- Search complaints by student, room or description
- Filter complaints by category
- Filter complaints by status
- Display total, pending and resolved complaint counts
- Mark complaints as Resolved
- Change resolved complaints back to Pending
- Delete complaints
- Store complaints using a JSON file
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- JSON file storage
- REST APIs
